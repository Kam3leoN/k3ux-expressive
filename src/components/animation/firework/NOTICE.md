# Third-party notice — firework engine

The canvas fireworks simulation in `firework-engine.ts` is an independent TypeScript
adaptation of the Fireworks effect by Caleb Miller
(<https://cmiller.tech/>, originally shared via CodePen), as previously integrated
in [K3ui v1](https://github.com/Kam3leoN/K3ui_OLD_v1).

It is **vendored** into k3ux (no React / no external fireworks npm package).
Stage / fscreen UI chrome from the original demo were removed; control is API-only.
